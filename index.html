特色

  • 自定义 AI：支持任意 OpenAI 兼容接口，地址 / Key / 模型一键配置，模型可自动搜索。
  • AI 本体（HIM）：连接游戏后聊天框提示「苍天有眼！我乃苍天会」，AI 以 HIM 造型降临，永久存在、不可推动、免疫火焰。
  • 玩家意识 + 永久记忆：AI 是"正儿八经的玩家"，陪玩、帮忙、绝不毁服；对话与任务永久保存。
  • AI 建造 / AI 操控：AI 可真实执行命令建造；AI 操控手机约 4 分钟后自动交还控制权。
  • 国旗：苍天旗（灰混凝土 + 木棍 + 黑混凝土）与五星红旗（红 / 黄混凝土 + 木棍）工作台合成。
  • 导入结构 / 光影：基岩版导入结构；Java 版导入结构（.nbt）与光影（shaderpacks）。
  • 检查更新：手机版设置页、Java 版 /gai update 均可检查 GitHub 最新版。

快速开始

手机版

  • 安装 APK → 同意 MIT 许可 → 授权存储 / 悬浮窗 / 无障碍
  • 设置中配置 AI（地址 / Key / 模型）→ 保存 → 启动悬浮窗
  • 面板「复制连接命令」→ 游戏内发送 → AI 分身降临

Java 版（Fabric / Forge）

  • 放入 mods/ → 进存档 → /gai config url|key|model …
  • /gai start 启动连接服务 → /gai spawn 召唤本体 → 聊天框 @AI 聊天
  • /gai update 检查更新 · /gai shader import / /gai structure import 导入光影与结构
