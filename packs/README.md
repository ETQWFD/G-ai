# G-ai 基岩版资源包与行为包

- `behavior/` — G-ai 行为包源码（AI 躯体实体 gai:ai_body、**内置 AI 分身脚本 scripts/main.js**、方块 gai:ai_core/gai:flag/gai:five_star、合成配方）
- `resource/` — G-ai 资源包源码（HIM 躯体模型贴图、旗帜贴图、语言文件）

安装：直接导入 Release 中的 `G-ai-基岩版整合包-v2.2.0.mcaddon`（行为包 + 资源包一次导入，AI 完全内置，不需要手机软件）。进入世界后聊天框输入 `@AI 你想让我干的事` 即可与 AI 对话。
